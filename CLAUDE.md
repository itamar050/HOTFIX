# Notes for Claude: HOTFIX! Nexus Meltdown

A 16-bit beat 'em up / platformer (Streets of Rage 2 look). Owner: itamar050. Work on `main`.
Separate projects always get their own repo (never `itamar050/frost`, which is firmware).

## Two versions in this repo

1. **Web version (complete, shipped):** `index.html` + `src/*.js`, vanilla JS/Canvas/WebAudio,
   320x224, all art/audio generated by code. 4 stages, 4 bosses, 2 heroes (Code Bro / Code
   Girl), menus, chiptune. See README.md. Desktop zips via Electron: bumping `version` in
   `package.json` and pushing makes `.github/workflows/release.yml` publish release
   `v<version>` (latest: v1.2.1). Keep it working; it is the playable game for now.
2. **Godot port (in progress):** `godot/`, Godot 4.4.1, 640x360, GL Compatibility, pixel
   snapping, integer scaling. Currently a stage 1 test slice: parallax far/wall/floor layers,
   Code Bro (`scripts/fighter.gd`: idle, walk, run on Shift, jab-jab-hook-kick chain that
   continues only on hit, face/gut hurt, knockdown fly/down/getup), a purple glitch clone
   sparring AI, hit sparks/hitstop/shake, HP bars, F2 hitboxes. Every push touching `godot/`
   runs `.github/workflows/godot-test.yml` -> pre-release `godot-test-N` (Win/Mac/Linux).

## Environment gotchas
- Pushing tags is blocked by the session git proxy: releases are created by workflows on push.
- The GitHub MCP release list hides pre-releases; check tags with `git ls-remote --tags origin`.
- Godot is not in the repo: download `Godot_v4.4.1-stable_linux.x86_64.zip` and
  `..._export_templates.tpz` (to `~/.local/share/godot/export_templates/4.4.1.stable/`) from
  the godotengine GitHub release.
- Test the slice: `godot --headless --path godot --import`, then
  `godot --headless --path godot -- --demo` (scripted input, prints state every 10 ticks,
  quits at tick 420). Frames: `xvfb-run -a godot --path godot --rendering-driver opengl3
  --write-movie out.png --fixed-fps 60 -- --demo`.
- GDScript: give explicit types when a value comes from the untyped `main`/`target` refs.
- Exports read `assets/sprites/*.json` at runtime: presets have `include_filter` for them;
  macOS export needs `textures/vram_compression/import_etc2_astc=true` (set).
- Run `codespell` on changed text (it flags short variable names).

## Art pipeline (Godot version)
- Raw art -> `art/raw/<char>_<anim>.png` (magenta #FF00FF background). Stage layers:
  `stageN_far|wall|floor`. Rejected art -> `art/raw/rejected/`.
- `python3 tools/import_art.py --preview` -> `art/sprites/` (+ `report.json` with warnings):
  keys magenta + pink fringe, finds figures as blobs, first figure of a strip = standing
  reference (sets scale, then dropped), characters 120 px tall in cells of 160x128 (wider
  in 32 px steps for wide poses), feet anchor (cell_w/2, 124), one 48-color palette per
  character, `_a/_b` files join into one strip. Per-file overrides in `art/raw/import.json`:
  `standing_px`, `drop`, `crop`, `scale`. Wall layers keep alpha (magenta windows).
- Copy used sprites + their `.json` to `godot/assets/sprites/`.
- `tools/breathe.py <strip> <frame> <out>`: idle loop from one frame (no AI shimmer).
- `tools/rig_walk.py`: cut-out puppet walk/run from the standing reference. Works (legs
  alternate) but the user finds it ugly: placeholder only, replace with drawn cycles.
- Stage 1 settings: far cropped pillar-to-pillar [212..1165] (loops); wall crop to y532,
  scale 0.7, drawn darker (0.86); floor crop below the concrete baseboard (y>=52), scale
  0.42, floor top 100 px above the feet, contact shadow at the seam.

## Gemini (Nano Banana) lessons
Good at single poses/attacks. Fails at walk cycles (never alternates legs, also as edits)
and idles (redraws = shimmer). Needs: PNG, <=4 figures per 16:9 image (~500 px figures),
standing reference first, wide gaps, "no blur", fresh chat with the character sheet
attached. Images cap at ~1024 px wide. The user finds the process slow and tedious.
